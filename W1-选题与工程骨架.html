壹知识点

1. 什么是陪伴型机器人

它和普通聊天机器人的区别不在"会不会聊天"，而在三件事：

能力普通聊天机器人陪伴型机器人（你要做的）
人格无固定人设，问什么答什么有名字、语气、边界，始终如一
知识库靠模型自带的通用知识靠你自己收集的领域语料，回答带出处
长期记忆关掉页面就忘了你跨会话记住用户的名字、偏好、经历
一句话记住本课题：知识是公共的（RAG 负责），记忆是私人的（记忆模块负责）。

2. 什么是 RAG（检索增强生成）

用户提问后，系统不是直接让大模型"凭印象"回答，而是先四步：

  1. 把问题转成向量（Embedding）
  2. 在你的知识库向量里找最相似的几段（检索 Top-5）
  3. 把找到的原文拼进提示词（"请根据以下资料回答……"）
  4. 模型基于资料生成回答，并标注出处

好处：答案可溯源、可控幻觉——知识库没有的就拒答，不编。

3. 选型三问（今天必须回答的问题）

① 陪谁？
选定一个人群（老人 / 儿童 / 备考生 / 新手爸妈 / 独居上班族……），写清他们的真实痛点。
② 答什么？
圈定知识库的 5 个主题域。超出范围的问题，机器人应当拒答。
③ 凭什么可信？
每个主题域要能公开找到 ≥30 篇可标注来源的语料，否则课题无法验收。
反面案例
"陪所有心情不好的人"——人群太泛、语料无法界定、评测无法出题。会被教师砍掉。

# 选题卡

（一类具体人群，一句话）
## 三个典型使用场景
1. …（谁，在什么时候，问什么）
2. …
3. …
## 知识库 5 个主题域
1. …  2. …  3. …  4. …  5. …
## 拒答范围
（哪些问题机器人必须拒绝或转人工，如：诊断病情、用药剂量）
## 语料可行性
（每个主题域列出 2–3 个公开来源：政府发布 / 权威机构指南 / 公开教材）
2
教师逐一过卡

判定标准只有一条：语料能否公开找到 ≥30 篇。找不到就当场换主题域或换人群。通过后教师签字。

3
写 1 页选型说明

由选题卡扩写，回答"为什么选这个陪伴对象、知识库为什么装这些内容"，300–500 字，存为 docs/选型说明.md。

这份文件是验收目标 4（选型讲得清）的第一份证据，W7 答辩要引用它。

叁第 2 节课：搭工程骨架 2 学时

4
装环境并自检

安装 Node.js 20 LTS、Git、VS Code。装完在终端逐条检查：

node -v    # 应输出 v20.x.x
npm -v     # 应输出 10.x.x
git --version
5
创建前端骨架
npm create vite@latest web -- --template vue-ts
cd web
npm install
npm run dev

浏览器打开 http://localhost:5173，能看到 Vite 默认页即通过。

6
开启 TS strict 模式（硬约束）

打开 web/tsconfig.json，确认：

{
  "compilerOptions": {
    "strict": true
    // …其余保持不变
  }
}
任务书验收 6 要求 strict 模式，现在不开，W7 补很痛。
7
创建服务端骨架（最小健康检查）
mkdir server; cd server
npm init -y
npm install express
npm install -D typescript @types/express tsx

新建 server/src/index.ts：

import express from "express";

const app = express();
app.use(express.json());

app.get("/api/health", (_req, res) => {
  res.json({ ok: true });
});

app.listen(3000, () => console.log("server on :3000"));

在 server/package.json 加启动脚本：

"scripts": { "dev": "tsx src/index.ts" }

运行 npm run dev，浏览器访问 http://localhost:3000/api/health，看到 {"ok":true} 即通过。

8
配置 ESLint + Prettier
cd web
npm install -D eslint prettier @typescript-eslint/eslint-plugin @typescript-eslint/parser

用 npx eslint . --fix 清理，要求：零 error（warning 可暂留）。

9

dist/
