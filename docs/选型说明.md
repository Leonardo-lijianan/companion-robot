# 选型说明

我选择的陪伴对象是城市独居老人。他们大多 65 岁以上，子女不在同城，生活基本自理但患有慢性病，平时会用微信，但不太会搜索和辨别网络信息。典型场景是：晚饭后一个人在家，遇到身体不适或想申请社区服务，不想频繁打扰子女，希望能有一个随时能问、靠谱的回答。

我选它，是因为我观察到身边许多长辈在慢病管理和社区服务上存在巨大的信息差。他们不是不需要帮助，而是怕麻烦别人，常常把“小问题”拖成“大问题”。如果有一个机器人能随时应答，能在一定程度上缓解这种焦虑。

知识库围绕慢病日常管理、日常用药常识、社区养老服务、手机防诈骗、情绪陪伴与求助 5 个主题域展开。计划收集 32 篇可标注来源的语料，来源以国家卫健委、中华医学会、民政部和公安部门公开发布的科普指南为主，确保每篇都能查到出处。

我明确不做：不下诊断、不给用药剂量、不预测寿命；涉及转账、汇款一律拒绝；知识库外的问题直接说“我的资料里没有”。如果涉及心理危机，我会直接提供 12356 心理援助热线和 120 急救电话。

7 周内我每周能稳定投入 4 小时以上。最大的风险是医疗合规要求，所以我准备把所有涉及“诊断、剂量调整、停药”的问题划入拒答范围，绝不越界。
