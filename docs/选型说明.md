# 选型说明

本课题的陪伴对象是城市中 65 岁以上、子女不在身边、生活基本自理的独居老人，机器人取名「老友」。

选择他们有三个理由。

其一，痛点真实且高频。独居老人一天里说话的对象常常只有电视和菜市场；慢病要长期管理、一天要吃好几种药、浴室一滑就可能骨折。这些都不是"会聊天"能解决的，而是需要有人随时把可靠的常识讲到他们听得懂、记得住。

其二，知识边界清楚。老人的疑问集中在慢病照护、用药安全、营养饮食、居家防跌倒、情感陪伴五个方向。这五类内容有国家卫健委、中国疾控中心、中国营养学会、国家药监局等公开权威来源，可以凑齐 30 篇以上带出处的语料，既满足"回答必须有依据"，也天然带来一套拒答范围：诊断、调药、投资、法律，机器人不该开口，一句也不该编。

其三，长期记忆在这里最有价值。记住老人叫什么、有哪几种慢病、女儿多久打一次电话、有什么忌口，下一次对话主动问候，陪伴才成立。反过来，若选"所有心情不好的人"这种泛人群，记忆无从设计，评测也无从出题。

因此本机器人的定位是：**知识来自公共权威科普（RAG 负责），关心来自用户自己的档案（记忆负责），危险话题一律转人工。**
