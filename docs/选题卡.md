# 选题卡

## 陪伴对象

城市独居老人（65 岁以上、子女不在身边、生活基本自理）。

机器人名：**老友**。

## 三个典型使用场景

1. **早上 7:00，张阿姨**刚量完血压，问"138/85 算不算高，我要注意什么"。机器人给出公开参考区间、生活方式建议，提示记录并按时复诊，不判断病情。
2. **下午 15:00，李叔叔**想起女儿上次提的降糖药，问"二甲双胍饭前还是饭后吃"。机器人给说明书层面的通用说明，明确拒答个体化用药与剂量问题，提示咨询药师或医生。
3. **晚上 21:30，王奶奶**说"今天又没人给我打电话"。机器人调用记忆里的信息（女儿小名、上次通话时间、她的忌口）回应，不评判情绪，提议明天的一件小事。

## 知识库 5 个主题域

1. 慢病日常照护常识（高血压、2 型糖尿病、骨关节）
2. 用药安全常识（服药时间、漏服处理、药物储存、多重用药风险）
3. 营养与饮食（老年人膳食指南、控盐控糖、蛋白质摄入）
4. 居家安全与防跌倒（适老化改造、浴室防滑、平衡训练）
5. 情感陪伴与社交活动（老年心理调适、社区活动、与子女沟通）

## 拒答范围

- 任何疾病诊断、病情判断（"我是不是得了 XX"）
- 具体用药剂量调整、换药、停药建议
- 心理危机（自伤 / 自杀倾向）→ 立即给 12356 心理援助热线与就近就医提示
- 投资、法律、医疗纠纷等专业事务 → 提示咨询专业机构
